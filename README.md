# مركز المباريات — خطوات التشغيل

| الجزء | المجلد | بيعمل إيه |
|---|---|---|
| السيرفر الوسيط | `worker/` | بيجيب البيانات من 4 مصادر مجانية، بيخبّي المفاتيح، بيعمل كاش مشترك |
| التطبيق | `www/` | مباريات بأي تاريخ، مباشر، بحث فرق، تفاصيل وإحصائيات |
| بناء أندرويد | `.github/workflows/` | بيطلّع ملف APK على GitHub من غير ما تنزّل أي برنامج |

## الجديد في النسخة دي
- **جدول الترتيب والهدافين:** اضغط على اسم أي دوري في تبويب المباريات، هتفتح صفحة الدوري فيها `الترتيب` و`الهدافين` — من `GET /standings?league=<id>` و`GET /scorers?league=<id>` (الـ id برقم API-Football، والموسم بيتحسب تلقائياً: من يوليو يبقى سنة الموسم هي السنة الحالية، وقبل كده السنة اللي قبلها).
- **التشكيلات:** صفحة تفاصيل المباراة بقى فيها تبويب تالت `التشكيلات` (التشكيلة، المدرب، الأساسية والبدلاء) — من `GET /fixture/:id`، والحقل الجديد `lineups`. لو التشكيلة لسه متعلنتش بيرجع `{}` وبيعرض رسالة بدل ما يبوظ الصفحة.
- **مايقعش:** ترتيب الـ fallback للمباريات والمباشر بقى: المزود الأساسي للدوري → المزود التاني (لو عنده مفتاح) → **ESPN من غير مفتاح** → **SportScore من غير مفتاح** → آخر نسخة محفوظة في الكاش مع `stale:true`. الـ fallback بيشتغل بس لما الأساسي يفشل أو يرجع فاضي، مش في كل طلب، عشان رصيد الخطط المجانية مايخلصش.
- **توفير الرصيد (مجاني):** football-data.org هو الأساسي لدورياته الـ 12 (10 طلبات/دقيقة، من غير حد يومي)، وAPI-Football بيتستخدم بس للدوريات اللي football-data.org مش بيغطيها (المصري والكؤوس...) وللإحصائيات والتشكيلات والتقييمات والمواجهات — وبيقف عند 85 من الـ 100 طلب المجاني في اليوم، وبعدها بيعتمد على ESPN وSportScore والكاش. حالة الرصيد بتظهر في `/health` (`apiFootball.dailyUsed` / `dailyBudget`).
- **مهلة 8 ثواني** لأي طلب خارجي، و`/health` بقى بيرجع حالة كل مصدر (`configured` / `available` / عدد الدوريات) من غير ما يسرّب أي سر.

## مين بيجيب إيه
- **football-data.org:** الدوريات الأوروبية الكبيرة (إنجلترا، إسبانيا، إيطاليا، ألمانيا، فرنسا، البرتغال، هولندا) ودوري أبطال أوروبا. مفيش إحصائيات تفصيلية. مجاني للأبد، 10 طلبات/دقيقة، من غير حد يومي.
- **API-Football:** الدوري المصري وباقي البطولات (الدوري الأوروبي، تركيا، بلجيكا، الكؤوس...) وإحصائيات المباريات والتشكيلات والتقييمات والمواجهات. مجاني 100 طلب/يوم — والسيرفر بيوقف استخدامه عند 85 طلب في اليوم عشان يفضل احتياطي.
- **ESPN (من غير مفتاح):** ملاذ أخير للمباريات والمباشر والترتيب والهدافين لما المصدرين اللي فوق يفشلوا.
- **SportScore (من غير مفتاح، ~10,000 طلب/يوم لكل IP):** آخر ملاذ للمباريات والمباشر بس. ملحوظة: الخطة المجانية بتاعته بتطلب إظهار "Powered by SportScore" في أي صفحة تعرض بياناته.
- لو مفتاح واحد بس موجود، السيرفر بيغطي اللي يقدر عليه بيه. ومن غير أي مفتاح بيشتغل **بوضع تجريبي** ببيانات وهمية.

> حدود الخطط المجانية بتتغير. راجع صفحة الأسعار في الموقعين قبل الاعتماد عليها.

## 1) المفاتيح
1. https://www.football-data.org → سجّل واحصل على الـ API token (مجاني).
2. https://www.api-football.com → سجّل وانسخ الـ API Key (الخطة المجانية 100 طلب في اليوم).

## 2) تشغيل السيرفر (Cloudflare Workers — مجاني)
محتاج Node.js (18 أو أحدث) وحساب مجاني على https://dash.cloudflare.com
```
cd worker
npm install
npx wrangler login

# الكاش المشترك (مهم عشان الطلبات ما تخلصش بسرعة)
npx wrangler kv namespace create CACHE
```
الأمر هيطبع رقم `id`. افتح `worker/wrangler.toml` وشيل علامة `#` من التلات سطور الخاصة بـ `kv_namespaces` وحط الـ id مكان `PASTE_THE_ID_HERE`. (لو الأمر ماشتغلش جرّب `npx wrangler kv:namespace create CACHE`.)

```
npx wrangler secret put FD_KEY      # الصق مفتاح football-data.org
npx wrangler secret put API_KEY     # الصق مفتاح API-Football
npx wrangler deploy
```
هيطلعلك عنوان زي `https://match-center-api.اسمك.workers.dev`. افتحه وأضف `/health` في آخره، لازم يظهر:
`"mock":false` و `"cache":"kv"` و`footballData` و`apiFootball` الاتنين `configured:true`. وجرّب كمان `/standings?league=39` و`/scorers?league=39` و`/fixture/af-XXXXXX` (أي id مباراة حقيقي) عشان تتأكد إن الترتيب والهدافين والتشكيلات شغالين.

## 3) ربط التطبيق
افتح `www/config.js` وحط العنوان في `API_BASE`.

## 4) طلّع ملف APK
1. اعمل مستودع جديد على https://github.com
2. ارفع كل الملفات. لو الرفع من المتصفح تجاهل المجلد المخفي `.github`، اعمل ملف جديد بالمسار `.github/workflows/android.yml` وانسخ محتواه.
3. من تبويب **Actions** اختار **Build Android APK** ثم **Run workflow**.
4. بعد حوالي 5 دقايق نزّل **Artifacts → match-center-apk** وفك الضغط، هتلاقي `app-debug.apk`. ثبّته على موبايل أندرويد.

## وضع التوفير
شغال افتراضياً (`ECONOMY = "1"` في `wrangler.toml`): قائمة اليوم تتحدث كل 10 دقايق تقريباً، والمباشر كل 3 دقايق، وصفحة الفريق كل 15 دقيقة. التأخير ممكن يوصل دقيقة أو اتنين (وأكتر شوية لأن الكاش المشترك KV بيتأخر في التحديث بين المناطق). الكاش المشترك KV هو اللي بيخلي طلب واحد من السيرفر يخدم كل المستخدمين — من غيره كل نسخة من الـ Worker بتحتفظ بكاش منفصل في الذاكرة، وده بيخلّي رصيد API-Football المجاني (100 طلب/يوم) يخلص أسرع بكتير.
لما تروح لخطة مدفوعة غيّره لـ `"0"` وأعد `npx wrangler deploy`.

## ملاحظات
- لو مصدر وقف أو خلص رصيده، التطبيق بيعرض آخر بيانات محفوظة ويكتب تنبيه.
- الـ fallback لـ ESPN بيغطي الدوريات دي بس: إنجلترا، إسبانيا، إيطاليا، ألمانيا، فرنسا، البرتغال، هولندا، تركيا، مصر، دوري الأبطال، الدوري الأوروبي، دوري المؤتمر. مباريات ESPN بتاخد id بيبدأ بـ `espn-`، وصفحة تفاصيلها بتعرض البيانات الأساسية من الكارت (التشكيلات والإحصائيات التفصيلية ليها مش متاحة من ESPN).
- الـ fallback لـ SportScore مفيهوش فلترة بتاريخ أو دوري، فهو بيرجع المباريات المباشرة والأخيرة وبعدين السيرفر بيفلترها بالتاريخ. مبارياته بتاخد id بيبدأ بـ `ss-`، وبتتجمع تحت دوري واحد باسم "SportScore" لأن الـ API مش بيرجع رقم دوري يتوافق مع أرقامنا — ده مقبول لأنه ملاذ أخير بس، وصفحة تفاصيلها بتعرض البيانات الأساسية من الكارت.
- البحث عن فريق أوروبي بيستخدم football-data.org، ولو ملقاش حاجة بيسأل API-Football (عشان نوفّر رصيده).
- **الدوريات:** القائمة في `worker/src/core.js` (`DEFAULT_LEAGUES`)، أو من غير تعديل كود بمتغير `LEAGUES` في `wrangler.toml`.
- **اسم التطبيق:** غيّر `appId` في `capacitor.config.json` لاسم خاص بيك قبل أي نشر.
